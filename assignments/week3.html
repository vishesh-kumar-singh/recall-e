Week 3

Week 3 Assignment

Train a PPO Agent for the Continual Bench

Assignment Instructions

The Task

Train the arm for any one selected task in the Continual-Bench environment using PPO.

Setup

Please download the assignment skeleton below, which contains the environment. Please don't try to use original continual bench repo, because there were missing texture files and we have also modified reward function to be more dense to aid learning.

One member from each team, download the zip and create a repository from this zip file, and give collaborator access to other members of your team. You guys may divide work amongst yourself, as well as once main part is done, your team each can try out different hyperparameters, reward functions etc. to improve the results.

Code skeleton is also provided so you could part be part understand the need of each function and get an idea of what is happening under the hood. It is advised to thoroughly go through the code and understand it.

Download Assignment Skeleton

Catastrphic Forgetting

Once you are done with training ppo, now you will try to show catastrophic forgetting. In order to do this, first you will train the agent for first few epochs on say door task. When you see a good performance in that, switch to a new task, say widow task and train the same Network over the new task. After this you will observe that the performance on door task has dropped significantly!!
