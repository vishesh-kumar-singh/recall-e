Week 2 Assignment

Train a Double DQN agent with Prioritized Experience Replay on Atari Boxing

Assignment Instructions

Submission: Make your own github repository(we reccommend you to collaborate using github) and push all the deliverables mentioned below.

Team Size: 5 members per team. Divide the modules among yourselves.

The Task

Train an agent to play Atari Boxing (ALE/Boxing-v5) using a Double DQN with Prioritized Experience Replay.

We have provided a modular code skeleton below. Each file contains the class and function signatures you need to implement. Your job is to fill in the logic.

Environment

Use the Gymnasium Atari environment:

import gymnasium as gym
import ale_py

gym.register_envs(ale_py)
env = gym.make("ALE/Boxing-v5")

You will need to install gymnasium[atari] and ale-py. The observation space is raw pixel frames (210×160×3). You'll need to preprocess these into grayscale, resize, and stack frames.

Code Structure

We provide the following modular file structure. Each file has its classes and function signatures pre-defined with pass. Your task is to implement the body of each function.

week-2/
├── env.py              # Environment wrappers and preprocessing
├── network.py          # Neural network architecture (Dueling optional)
├── replay_buffer.py    # Prioritized Experience Replay buffer
├── agent.py            # Double DQN Agent (action selection, learning)
├── train.py            # Training loop and logging
├── evaluate.py         # Evaluation and rendering
├── config.py           # All hyperparameters in one place
└── README.md           # Your analysis and instructions

Module Breakdown

  • config.py — Central config file. All hyperparameters (learning rate, batch size, gamma, epsilon schedule, PER alpha/beta, etc.) live here.
  • env.py — Gymnasium wrappers to handle frame preprocessing: grayscale conversion, resizing to 84×84, frame stacking (4 frames), and reward clipping.
  • network.py — The CNN architecture that takes stacked frames as input and outputs Q-values for all 18 actions.
  • replay_buffer.py — The Prioritized Experience Replay buffer using a Sum Tree data structure for O(log n) sampling.
  • agent.py — The Double DQN agent: epsilon-greedy action selection, target network updates, and the learning step using PER priorities.
  • train.py — The main training loop: environment interaction, storing transitions, periodic learning, logging rewards, and saving checkpoints.
  • evaluate.py — Load a trained model and run evaluation episodes. Optionally record video.

What to Submit

  • All completed Python files with working implementations.
  • Training plots: episode reward vs. episode number (smoothed).
  • A README.md with:
    • How to install dependencies and run training.
    • Training hyperparameters used.
    • Link your model weights uploaded on google drive(ofc you can not push large files on github).
    • Brief analysis on the performance of your agent.
    • Division of work among team members.

Hints

  • Start with config.py and env.py — get the environment running and rendering first.
  • Build and test network.py independently — make sure the forward pass shapes are correct.
  • Implement a simple uniform replay buffer first in replay_buffer.py, then upgrade to PER.
  • The Sum Tree is the trickiest part. Draw it out on paper before coding.
  • Use torch.no_grad() when computing target Q-values.
  • Sync the target network every few thousand steps, not every step.
