Python Basics

Python is the language we'll use for everything in this project, from simple scripts to training RL agents. Make sure you're comfortable with the fundamentals: variables, loops, functions, and especially classes (OOPs), since most ML libraries are built around them. If you already know Python, skim through these as a refresher.

  • Variables, data types, control flow, functions
  • List comprehensions, lambda expressions
  • Classes and basic OOPs concepts

Machine Learning Foundations

Before jumping into RL, it helps to understand how machines learn from data. Linear and logistic regression are the simplest ML algorithms and introduce key concepts like cost functions, gradient descent, and overfitting that carry over directly to deep RL.

  • Linear Regression: fitting a line, cost function, gradient descent
  • Logistic Regression: sigmoid function, binary classification
  • Evaluation: confusion matrix, train-test split

Neural Networks

Neural networks are the function approximators that make deep RL possible. In this project, we'll use them as policy networks (PPO) and world models. Understanding how a basic neural net learns through backpropagation is essential, and the 3Blue1Brown series is a must-watch.

  • Perceptrons and multi-layer perceptrons
  • Activation functions, backpropagation
  • CNNs (overview)
  • PyTorch / TensorFlow / Scikit-learn intro
